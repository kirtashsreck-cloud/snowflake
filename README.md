# ❄ Copo de Nieve

Planificador de novelas basado en el método del copo de nieve de Randy Ingermanson.

## Qué incluye

- Los 10 pasos del método del copo de nieve, cada uno como página navegable.
- Fichas de personaje (breves, sinopsis y biblia completa).
- Lista y plan de escenas con verificador de escenas proactivas/reactivas.
- Panel de ejemplos con el caso de Ricitos de Oro.
- Exportación a Markdown, PDF, DOCX y JSON.
- Guardado automático y manual, historial de versiones, temas claro/oscuro.

## Cómo usarlo

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador.
3. Empieza a planificar.

No requiere instalación ni servidor. Todo funciona en el navegador.
